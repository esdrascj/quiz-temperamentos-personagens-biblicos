# Quiz dos Temperamentos – Encontro de Jovens 🌟

Um aplicativo web interativo, desenvolvido especialmente para encontros e cultos de jovens, com o objetivo de testar e aprimorar o conhecimento sobre os **4 Temperamentos** (Sanguíneo, Colérico, Melancólico e Fleumático) através de cenários práticos, reações comportamentais e exemplos bíblicos.

---

## 🚀 O que a Aplicação Oferece?

* **10 Perguntas Desafiadoras:** Questões dinâmicas que abordam o dia a dia, reações sob pressão, resolução de conflitos e figuras bíblicas.
* **Feedback Imediato:** Explicação detalhada após cada resposta, mostrando o porquê daquele temperamento.
* **Pontuação Final com Feedback Personalizado:** Mensagem de incentivo baseada no desempenho do participante.
* **Modo Múltiplos Jogadores (Reset Fácil):** Botão de reinício rápido ao final do teste, permitindo que vários jovens usem o mesmo celular ou tablet em sequência durante o evento.
* **Design Responsivo e Moderno:** Interface limpa, com cores suaves e ícones intuitivos, otimizada para telas de smartphones.

---

## 🛠️ Tecnologias Utilizadas

* **HTML5:** Estrutura semântica da página.
* **CSS3:** Estilização moderna, variáveis customizadas, Flexbox/Grid e animações suaves.
* **JavaScript (Vanilla):** Lógica do quiz, controle de estado, embaralhamento opcional e manipulação dinâmica do DOM.

---

## 📦 Como Usar / Executar

Como a aplicação é construída em um único arquivo HTML contendo todo o código CSS e JavaScript embutido, executá-la é extremamente simples:

1. Salve o código da aplicação em um arquivo com o nome **`index.html`**.
2. Dê um duplo clique no arquivo para abri-lo em qualquer navegador web atualizado (Google Chrome, Safari, Edge, Firefox).
3. Pronto! O quiz já estará rodando e pronto para ser usado no projetor ou nos celulares dos jovens.

---

## 📱 Dicas para o Encontro de Jovens

* **Dinâmica de Grupo:** Projete a tela do celular/computador em uma TV ou telão para que todos participem respondendo coletivamente antes de revelar a resposta.
* **Passar o Aparelho:** Utilize o botão **"🔄 Reiniciar Quiz - Novo Jogador"** ao final para convidar diferentes jovens a testarem seus conhecimentos individualmente.
* **Conexão Bíblica:** Aproveite as explicações do quiz para abrir a Bíblia e debater como cada temperamento pode ser lapidado pelo Fruto do Espírito Santo (Gálatas 5:22-23).
